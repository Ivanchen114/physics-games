# 法則神殿：失序紀元｜高中物理雙軌闖關

松山高中物理科設計的十二座物理神殿，共 97 道關卡。每座神殿分成：

- 高一初階殿：觀察、預測、操作變因與質性判斷
- 高二／高三進階殿：模型選擇、計算與證據驗證

玩家扮演「法則修復者」，以可恢復的三格神火、法則經驗、無傷刻印、連勝與雙印遺物推進世界故事。答錯會消耗神火；神火歸零時由守護者啟動回溯與提示，不會永久封鎖學習。

首頁提供推薦下一關、三步證據循環與四幕遠征進度；玩家仍可自由選殿。原創神殿音景與操作音效由 Web Audio API 即時合成，不使用外部音樂素材、不會自動播放，並提供持久化的開關控制。首次通關另有可被「減少動態」偏好停用的刻印粒子回饋。

## 本機驗證

```bash
npm test
npm run build
```

正式建置輸出位於 `dist/client`。`games/` 保留舊版五座神殿作為歷史版本，正式站不會輸出該目錄。既有 `law-temple-v3-*` 闖關進度鍵刻意保留，以避免升級後清除學生進度；v4 玩家檔案另存於 `law-temple-v4-player`。
