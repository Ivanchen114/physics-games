📘 不確定度補充

組合不確定度計算：

  • uA = s / sqrt(n)
  • uB = LC / sqrt(12)
  • uC = sqrt(uA² + uB²)

若多次量測皆相同 → 推估為儀器刻度不確定度（B 類）

✨ 有效位數原則：

  • 不確定度：保留 2 位有效數字（無條件進位）
  • 測量值：小數位需與不確定度一致

📘 單次量測的不確定度計算

因只量一次，屬於 B 類不確定度：

  • LC = 0.1 cm
  • u = LC / sqrt(12) = 約 0.029 cm

組合不確定度：僅來自儀器刻度

主測量值小數位需與 u 一致（尾數對齊）

📘 加法誤差傳播定律

周長公式：P = 2L + 2W

不確定度：uP = sqrt((2uL)² + (2uW)²)

✨ 小數位需與 uP 對齊

📘 乘除法誤差傳播定律

體積：V = L × W × H

uV / V = sqrt( (uL/L)² + (uW/W)² + (uH/H)² )

密度：ρ = m / V

uρ / ρ = sqrt( (um/m)² + (uV/V)² )

✨ 結果需符合有效位數原則，小數位與不確定度尾數一致

📘 統計型不確定度（A 類）+ B 類合併計算

  1. 平均值：x̄ = (Σx) / n
  2. 樣本標準差：s = sqrt(Σ(xi - x̄)² / (n - 1))
  3. uA = s / sqrt(n)
  4. uB = LC / sqrt(12)
  5. uC = sqrt(uA² + uB²)

✨ 最終答案應保留 2 位有效數字，並與主測量值尾數一致
